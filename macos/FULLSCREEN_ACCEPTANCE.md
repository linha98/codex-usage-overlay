# macOS 全屏隐藏验收

验收日期：2026-10-26。本机安装路径：`/Applications/Codex悬浮窗.app`。

## 实际浏览器验收

| 场景 | 结果 |
| --- | --- |
| Chrome：YouTube 播放器进入全屏 | 检测到 `AXFullScreen=true`，悬浮窗不可见 |
| Chrome：YouTube 按 Escape 退出全屏 | 连续确认普通窗口后自动恢复 |
| Chrome：YouTube 保持全屏跨过一分钟刷新周期 | 连续 39 次检测均为隐藏、不可见，没有重新弹出 |
| Chrome：上述持续全屏后按 Escape | 自动恢复，实际界面正常显示用量和重置次数 |
| Chrome：Bilibili 播放器进入全屏 | 检测到 `AXFullScreen=true`，悬浮窗不可见 |
| Chrome：Bilibili 未登录试看结束，网站退出全屏 | 悬浮窗随退出全屏自动恢复 |
| Safari：Bilibili 播放器进入全屏、Escape 退出 | 隐藏和恢复均正常 |

另已通过优化构建、应用签名校验和 `git diff --check`。安装的可执行文件与本次构建 SHA-1 一致：`8a8602a4fa23cd02ab5fb5d57c1d8b9820388424`。

## 检测行为

- 优先读取前台窗口明确的全屏状态，辅以屏幕覆盖范围。
- 辅助功能查询有单次超时与整轮时间预算，不再无限等待浏览器。
- 切换前台应用后丢弃旧检测结果，监听 Space 切换。
- 退出全屏经过连续确认后恢复，正常需要约 2–4 秒。
- 无法确定状态时不把查询失败直接当作退出全屏。

本次现场覆盖 Chrome 和 Safari；未现场覆盖其他浏览器、游戏、多显示器和撤销辅助功能权限的情况。
